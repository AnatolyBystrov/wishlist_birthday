# Вишлист Анатолия

Сайт-вишлист ко дню рождения. Гости открывают ссылку с телефона, выбирают подарок и жмут «Я подарю». Регистрация не нужна.
Именинник управляет списком по секретной ссылке.

Сайт статичный (GitHub Pages), брони хранятся в бесплатной базе Supabase.
Пока база не подключена, сайт работает в демо-режиме с примерами.

## Как подключить базу (5 минут, один раз)

1. Зайди на [supabase.com](https://supabase.com), войди через GitHub и создай проект (Free plan, регион поближе, например Frankfurt).
2. Открой **SQL Editor → New query**, вставь целиком файл [`supabase/schema.sql`](supabase/schema.sql) и нажми **Run**.
   Внизу появится `admin_key`: это ключ от панели именинника, сохрани его.
3. Открой **Project Settings → API** (или кнопку **Connect**) и скопируй:
   - **Project URL** (вида `https://xxxx.supabase.co`);
   - ключ **anon public** или **publishable**.
4. Впиши их в [`config.js`](config.js) и сохрани коммит.

Оба значения из шага 3 можно публиковать: база разрешает только то, что описано в `schema.sql`.
Гости могут читать список и бронировать подарки. Менять список можно только с `admin_key`.

## Как включить сайт

**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.**
Через минуту сайт будет по адресу `https://anatolybystrov.github.io/wishlist_birthday/`.

## Ссылки

- **Для гостей:** `https://anatolybystrov.github.io/wishlist_birthday/`
- **Для тебя (никому не показывай):** `https://anatolybystrov.github.io/wishlist_birthday/#admin=ТВОЙ_admin_key`
  Открой её один раз на своём телефоне: браузер запомнит ключ, и дальше панель будет открываться по обычной ссылке.

## Как это устроено

- `index.html`: вся страница (дизайн, музыка «Хава Нагила» на Web Audio, анимации).
- `config.js`: адрес и публичный ключ Supabase.
- `supabase/schema.sql`: таблицы, правила доступа и функции:
  - на каждый подарок может быть только одна бронь, двойную не даст сама база;
  - снять бронь может только тот, кто её поставил (по секретному токену в его браузере);
  - добавлять, менять и удалять желания можно только с `admin_key`.
